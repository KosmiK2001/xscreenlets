# conlog — вывод команды на рабочем столе

Апплет показывает вывод команды, которую задаёт пользователь. Запускает
её один раз, читает вывод асинхронно и держит последние строки с
прокруткой назад. Похож на текстовые блоки Conky (`dhclient`, `dmesg`,
`journalctl -f`), но живёт внутри XScreenlets.

## Как работает

1. Команда запускается через `GSubprocess` без оболочки — аргументы
   разбираются из строки и передаются процессу напрямую.
2. stdout читается `GIOChannel` в неблокирующем режиме, обработчик
   вызывается из главного потока GTK. Поток никогда не ждёт процесс.
3. Вывод режется на строки по переводу строки. Строка, пришедшая
   несколькими порциями, склеивается и показывается целиком.
4. Старые строки вытесняются при достижении `max_lines`.
5. stderr отбрасывается, чтобы ошибки не смешивались с выводом.

## Настройки

| Ключ | Смысл | По умолчанию |
|---|---|---|
| `command` | команда для запуска | `dmesg --follow` |
| `max_lines` | сколько строк хранить | 200 |
| `colorize` | подсветка по уровню сообщения | 1 |
| `wrap` | перенос длинных строк | 0 |
| `strip_ansi` | вырезать escape-последовательности | 1 |
| `autoscroll` | следовать за хвостом | 1 |
| `row_font` | шрифт строк | `Monospace 9` |
| `line_step` | шаг строк; 0 = по высоте шрифта | 0 |
| `width_auto` | ширина по содержимому; -1 = не задана | 0 |
| `height_auto` | высота по содержимому; -1 = не задана | 0 |

Цвета задаются как `rgba(r,g,b,a)`: `row_color`, `background_color`,
`border_color`, `color_normal`, `color_warn`, `color_error`,
`color_info`, `color_debug`.

## Подсветка по уровню

Уровень определяется по слову в строке, регистр не важен, слово должно
стоять целиком:

- **ошибка** — `error`, `err`, `fail`, `failed`, `failure`, `critical`,
  `crit`, `fatal`, `panic`, `denied`, `refused`;
- **предупреждение** — `warn`, `warning`, `deprecated`;
- **отладка** — `debug`, `trace`;
- **инфо** — `info`, `notice`, `started`, `connected`, `loaded`;
- **обычное** — всё остальное.

Окончания перечислены явно: `fail` не находит `failed`, а именно эту
форму пишет systemd (`FAILED to start …`). Проверка идёт по границе
слова, поэтому `errorless` остаётся обычным сообщением.

## Примеры

```ini
command=journalctl -f -n 20
max_lines=300
colorize=1
```

```ini
command=dmesg --follow
max_lines=100
row_font=Monospace 8
```

```ini
command=ip monitor link
colorize=0
```

## Ограничения

- Команда запускается один раз. Чтобы увидеть вывод после её
  завершения, поменяй команду в Настройках — она перезапустится.
  Автоматического перезапуска нет намеренно: иначе завершившийся
  `date` через секунду стартовал бы снова.
- Вывод берётся только из stdout. Если команда пишет в stderr,
  перенаправь сам: `command=sh -c dmesg -w 2>&1`.
- Состояние между перезапусками не сохраняется: после рестарта демона
  буфер пуст и команда стартует заново.
