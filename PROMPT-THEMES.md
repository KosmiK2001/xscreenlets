# PROMPT-THEMES.md — промпт для LLM-генераторов тем frame_launcher

Этот файл — ТЗ для генерации НОВОЙ темы рамки frame_launcher (xscreenlets).
Скорми этот файл целиком LLM-генератору вместе с описанием желаемого
визуала («тема в стиле敦 Chrysler Building, тёмная бронза») — на выходе
должен получиться каталог темы с файлами, описанными ниже.

## Куда класть готовую тему

Пользовательская тема:
  ~/.config/xscreenlets/themes/frame_launcher/<имя_темы>/
Системная тема (для всех пользователей):
  /usr/share/screenlets/FrameLauncher/themes/<имя_темы>/

Включение: в конфиге инстанса рамки
  (~/.config/xscreenlets/.plugins/frame_launcher-*.conf) ключ
  theme=<имя_темы>. Смена темы на живой рамке — через Properties →
  Frame → Theme (поле имени).

## Формат поставки

Каталог с файлами, заzip-ованный: <имя_темы>.zip, внутри —
<имя_темы>/theme.conf + *.svg. Установка = распаковать в один из
каталогов выше (zip должен содержать каталог темы в корне).

## Обязательные файлы темы

### 1. theme.conf

[Theme]
name=Human Readable Name
author=...
version=1.0
info=Краткое описание

[frame_launcher]
frame_left=N      ; толщина ЛЕВОЙ рамки, px (см. геометрию ниже)
frame_right=N
frame_top=N
frame_bottom=N

Эти 4 числа — МАКЕТ 9-slice: они делят окно рамки на 9 зон.
Они же определяют content-зону (зону гостей):
  content_x = frame_left + shadow
  content_y = frame_top + shadow
  content_w = width - frame_left - frame_right - 2*shadow
  content_h = height - frame_top - frame_bottom - 2*shadow
(«shadow» — ключ в конфиге инстанса, 2..4 px, зона затенения между
рамкой и content-зоной.)

### 2. Девять SVG (9-slice, без которых тема не соберётся)

Имена файлов = имена элементов. Каждый SVG — в НАТУРАЛЬНОМ размере
своей зоны (width/height обязаны быть в px и совпадать с зоной).

| Файл          | Зона                  | Рекомендуемый размер |
|---------------|-----------------------|----------------------|
| frame-tl.svg  | верхний левый угол    | frame_left × frame_top |
| frame-tr.svg  | верхний правый угол   | frame_right × frame_top |
| frame-bl.svg  | нижний левый угол     | frame_left × frame_bottom |
| frame-br.svg  | нижний правый угол    | frame_right × frame_bottom |
| frame-top.svg | верхняя сторона       | 8 × frame_top (тянется по X) |
| frame-bottom.svg | нижняя сторона     | 8 × frame_bottom (тянется по X) |
| frame-left.svg   | левая сторона      | frame_left × 8 (тянется по Y) |
| frame-right.svg  | правая сторона     | frame_right × 8 (тянется по Y) |
| backdrop.svg     | фон content-зоны   | 16 × 16 (тянется по XY) |

Правила:
- svg КОРЕНЬ обязан иметь width/height в px (по ним код берёт
  натуральный размер; viewBox желателен).
- В боковых/фоновом svg добавь preserveAspectRatio="none" — их
  растягивают по одной/двум осям.
- Углы (frame-tl и т.п.) рисуются В НАТУРАЛЬНОМ размере (1:1),
  никаких preserveAspectRatio не нужно.
- Прозрачность ДЕЛАЙ честной альфой SVG (stop-opacity / fill-opacity):
  рамка рендерится на прозрачном ARGB-окне, композитор сам смешает.
- Гости рисуются ПОВЕРХ рамки, внутри content-зоны. Не рисуй в
  backdrop ничего контрастного — поверх него живут апплеты.

### 3. Опционально: единый frame.svg (простые темы)

Если у темы нет 9-slice элементов, но есть frame.svg — он растянется
на всё окно целиком (быстро, но углы/стороны исказятся при сильном
изменении пропорций). Для качественных тем всегда используй 9-slice.

## Как код использует тему (для понимания, менять не нужно)

- При отрисовке: backdrop → 4 угла (native) → 4 стороны (растяжка
  между углами). Если есть frame-tl ИЛИ frame-top — режим 9-slice
  включается автоматически.
- Прозрачность рамки целиком (opacity) и фона (bg_opacity) — из
  конфига инстанса, тема про них не заботится.

## Чек-лист генератору

- [ ] theme.conf: [Theme] + [frame_launcher] с 4 толщинами
- [ ] 9 svg с точными именами, корневые width/height в px
- [ ] preserveAspectRatio="none" на тянущихся элементах
- [ ] Углы визуально «замыкаются» со сторонами (одинаковые цвета
      на стыках, непрерывная кромка)
- [ ] Ничего важного не нарисовано ближе 2px к краю (antialiasing
      на прозрачном окне)
- [ ] Запаковано: <имя_темы>.zip → <имя_темы>/...

## Пример визуального брифа для генерации

«Сделай тему "aero-bronze": тёмная бронза, матовая, тонкая светлая
кромка 1px #d8c9a0 сверху и слева, внутри лёгкая вертикальная
текстура. Толщины рамок 10px, радиус скругления 6px.»
→ LLM генерирует theme.conf + 9 svg по правилам выше, упаковывает
в aero-bronze.zip.
